# Modern Personal Portfolio

A stunning, responsive personal portfolio website built with React, JavaScript, Tailwind CSS, and advanced animations using Framer Motion.

## ✨ Features

- **Modern Design**: Sleek, professional design with glass morphism effects
- **Advanced Animations**: Smooth animations and transitions using Framer Motion
- **Interactive Graphics**: Particle background system and dynamic visual effects
- **Responsive Design**: Fully responsive across all devices and screen sizes
- **Performance Optimized**: Fast loading with optimized assets and code splitting
- **Accessibility**: Built with accessibility best practices in mind

## 🛠️ Tech Stack

- **React 18**: Modern React with hooks and functional components
- **Vite**: Fast build tool and development server
- **Tailwind CSS**: Utility-first CSS framework for rapid styling
- **Framer Motion**: Production-ready motion library for React
- **Lucide React**: Beautiful and customizable SVG icons
- **React Intersection Observer**: Efficient scroll-based animations
- **Typewriter Effect**: Dynamic typing animations

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.

## 🎯 Customization

### Personal Information
Update the following files with your personal information:
- `src/components/Hero.jsx` - Name, title, and description
- `src/components/About.jsx` - Personal story and background
- `src/components/Projects.jsx` - Your projects and portfolio items
- `src/components/Contact.jsx` - Contact information and social links

### Styling
- Colors and themes can be customized in `tailwind.config.js`
- Custom animations are defined in `src/index.css`
- Component-specific styles are in individual component files

### Content
- Replace placeholder images with your actual project screenshots
- Update project descriptions and technology stacks
- Customize skills and proficiency levels
